FEATURES

小体积，大本事。

单文件约 6 MB，没有浏览器插件，没有账号体系。只做一件事：把 MEGA 链接变成你硬盘上的文件，又快又稳。

多线程下载

单文件多连接并发，大带宽直接跑满。线程数、全局限速都可在设置里精细调节。

断点续传与自愈v2.5

暂停、恢复、失败自动定时重试；彻底失败的任务会被隔离，不再拖慢队列。

复制即捕获

剪贴板监听自动识别 MEGA 链接，也可以手动粘贴、直接把链接拖进主窗口。

整文件夹解析

递归解析分享文件夹，可只勾选需要的子目录和文件下载，不浪费一字节流量。

配额熔断v2.5

MEGA 配额耗尽时自动暂停并倒计时，恢复后继续——不用半夜爬起来点恢复。

边下边播 · 自动解压

集成 VLC 串流，未下完先睹为快；RAR / 7Z / ZIP 下完自动解压，一步到位。

HOW IT WORKS

三步，从链接到文件。

没有注册，没有登录，没有浏览器插件。流程短到不好意思写文档。

01下载即运行

选便携版解压即用，或选单文件版双击直达。最低支持 Windows 7 SP1，需 .NET 4.8。

02复制链接

复制 mega.nz/file/… 或文件夹链接，剪贴板监听会自动捕获；也可以拖进窗口。

03开始下载

多线程全速开跑，断点续传、配额熔断、失败自愈都在后台默默工作。

FAQ

你可能想问。

先看这里，没有答案就去仓库提 Issue。

完全免费，MIT 开源，无广告、无捆绑、无账号体系。代码全部公开在 GitHub，Release 构建由 Actions 流水线自动完成，任何人都可以审查和自行编译。

原版作者 Andres Soliño 在 v1.8 后停止维护，而 MEGA 更换了链接格式导致老版本无法识别新链接。本项目从 v1.8 反编译源码出发修复兼容性并持续改进（已应用 60+ 处修复），原版权归 Andres Soliño 所有，复活部分的修改遵循 MIT 协议开源。

软件本身不限速，多线程可跑满你的带宽。MEGA 免费账号有配额限制，v2.5 新增的配额熔断会在配额耗尽时自动暂停并倒计时，恢复后自动继续下载。

支持新版 mega.nz/file/、mega.nz/folder/、旧版 mega.nz/#! 以及 enc / enc2 / elc 等加密链接。分享文件夹可递归解析，支持只勾选部分子目录和文件。

需要 Windows 7 SP1 及以上 + .NET Framework 4.8（Win10/11 自带）。小众开源 exe 偶尔会被杀软误报：请认准 GitHub Releases 官方构建并核对 SHA256；介意的话可以直接用源码自行编译——这正是开源的意义。

内置 10 种语言（含简体中文），深色 / 浅色 / 跟随系统三种主题，切换即时生效。
